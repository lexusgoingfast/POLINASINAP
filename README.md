# NASEKOLINA — архив Полины Кузьминой

Статичный одностраничный сайт: HTML, CSS и JS без сборки и зависимостей.

```
index.html               разметка
assets/style.css         стили
assets/app.js            сетка, подборки, фильтр, инверсия, просмотр работы
assets/fonts/            шрифты (в репозитории их нет, см. ниже)
assets/hero/             анимация знака из TouchDesigner: ролик и постер
assets/footer/           ролики подвала из TouchDesigner: loop-NN.mp4 и постеры
data/works.js            ВСЁ содержимое: тексты сайта, подборки, список работ
img/<работа>/NN-t.webp   миниатюра для «Подборок» (320 px)
img/<работа>/NN-s.webp   превью для сетки (800 px)
img/<работа>/NN-l.webp   кадр для просмотра (2000 px)
tools/prepare_images.py  подготовка новых фотографий
tools/prepare_fonts.py   шрифты → WOFF2
tools/prepare_hero.py    ролик знака из TouchDesigner → assets/hero/
tools/prepare_footer.py  ролики подвала из TouchDesigner → assets/footer/
tools/loops.py           общее для двух скриптов: порог, H.264, постер
tools/agentation-dev.js  панель заметок для Claude (только localhost)
```

## Посмотреть локально

```bash
python3 tools/serve.py
```

Затем открыть http://localhost:4173. Сервер слушает всю сеть и при запуске печатает адреса,
поэтому сайт можно открыть с телефона в той же Wi-Fi сети. Вместо `python3 -m http.server` нужен именно он:
Safari на iPhone не проигрывает видео с серверов без поддержки Range-запросов.

## Добавить работу

1. Сложить фото работы в отдельную папку.
2. Выполнить (нужен Python 3 и Pillow):

   ```bash
   python3 tools/prepare_images.py "путь/к/папке" имя-работы
   ```

3. Скрипт выведет готовый блок — вставить его в начало массива `WORKS`
   в `data/works.js` и заполнить поля. Незаполненные поля на сайте
   показываются как «будет добавлено».

Порядок элементов в `WORKS` задаёт порядок плиток в сетке.
В поле `grid` указываются кадры, которые попадут в сетку:
`size: 's'` — обычная плитка, `'w'` — широкая, `'l'` — большая 2×2.

## Подборки

Раздел «Подборки» собирается сам: `SITE.edits` в `data/works.js` — это строки с крупным названием
и списком категорий (`cats`). Новая работа с подходящей категорией попадает в ленту без правок.
Клик по названию показывает эти категории в архиве, «Весь архив» снимает фильтры.

## Как устроен просмотр

- Любая работа открывается по прямой ссылке: `/#/round-bag/3` (работа и номер кадра).
- На компьютере: стрелки ↑↓ листают кадры, Esc закрывает.
- На телефоне кадры листаются свайпом.
- Панель внизу: «Инверт» (переворачивает сайт целиком: белый лист, чёрный текст, фото позитивом,
  знак NASEKOLINA тоже), «Фильтр» (тип и год), 1–4 (плотность сетки), ✕ (сбросить вид).
  Выбор запоминается в браузере. Цветной оригинал фото проявляется при наведении
  (на телефоне — у плитки в центре экрана).
- Единственная стрелка сайта — Forma Icons, line / arrow-right (спрайт `#i-arrow` в `index.html`);
  остальные направления получаются поворотом. «→» в текстах работ превращается в неё же.

## Анимация знака (TouchDesigner)

Знак NASEKOLINA на первом экране — ролик из TouchDesigner: `assets/hero/hero-loop.mp4` и постер
`hero-poster.webp`. Нужен один ролик «белое на чёрном»: инверт-версия не требуется. В браузере каждый
кадр проходит жёсткий порог (строго чёрное и белое, заодно исчезает шум сжатия), а кнопка «Инверт»
переворачивает его вместе со всей страницей.

Обновить после нового экспорта (нужны ffmpeg и Pillow):

```bash
python3 tools/prepare_hero.py "путь/к/hero-loop.mp4"
```

Или оставить работать и пересобирать при каждом экспорте, тогда достаточно обновить страницу:

```bash
python3 tools/prepare_hero.py "путь/к/hero-loop.mp4" --watch
```

Скрипт заранее пропускает кадры через порог, кодирует H.264 без звука (`--crf`: больше — легче файл, по умолчанию 30)
и делает постер из первого кадра. Ролик ставится на паузу, когда первый экран не виден или вкладка скрыта,
а при включённом «уменьшении движения» в системе показывается только постер. Если ролика нет, вместо
него виден текстовый знак (Punkbabe). Уровень порога в браузере — CSS-переменная `--hero-th` (0…1, по умолчанию 0.5).

## Анимация подвала (TouchDesigner)

В подвале, на всю ширину экрана, играет один из роликов `assets/footer/loop-01.mp4`, `loop-02.mp4`, …:
при каждом открытии сайта выбирается случайный, кнопка «Другой кадр» берёт следующий случайный.
Подпись под роликом ведёт на работу `SITE.footerWork` (сейчас «Жамэвю»). Порог и инверт те же, что у знака:
кадр строго чёрно-белый и переворачивается вместе с сайтом; уровень порога — CSS-переменная `--foot-th`.
Ролик грузится, только когда подвал близко к экрану.

Собрать из папки с экспортом (каждому .mp4 из папки достанется свой номер; нужны ffmpeg и Pillow):

```bash
python3 tools/prepare_footer.py "путь/к/папке/web"
```

С `--watch` скрипт пересобирает изменённые ролики сам, после экспорта достаточно обновить страницу:

```bash
python3 tools/prepare_footer.py "путь/к/папке/web" --watch
```

Число роликов записано в `data/works.js` (`footerLoops`); если оно не совпадает с числом файлов, скрипт напомнит.
Плотный полутон сжимается хуже логотипа, поэтому по умолчанию `--crf 34` (около 2,3 МБ на ролик).

## Шрифты

Neue Haas Grotesk Display Pro и Punkbabe — платные шрифты, в репозиторий они не входят.
Как собрать файлы из своих: [assets/fonts/README.md](assets/fonts/README.md).
Для публикации сайта нужны веб-лицензии на оба шрифта. Punkbabe trial — «free for personal use only»;
в нём заглавные буквы нарисованы как строчные, поэтому знак читается как «nasekolina».

## Заметки для Claude (Agentation)

На localhost в углу страницы появляется панель [Agentation](https://www.agentation.com/): кликнуть
элемент, написать заметку — Claude получит её вместе с селектором. Работает через MCP-сервер:

```bash
claude mcp add agentation -- npx -y agentation-mcp server
```

После добавления перезапустите сессию Claude Code. Панель грузится с CDN только на localhost
(`tools/agentation-dev.js`, версии закреплены); отключить на странице — `?annotate=0`.
