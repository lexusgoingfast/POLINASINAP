# NASEKOLINA — архив Полины Кузьминой

Статичный одностраничный сайт: HTML, CSS и JS без сборки и зависимостей.

```
index.html               разметка
assets/style.css         стили
assets/app.js            подход, сетка, фильтр, инверсия, просмотр работы
assets/fonts/            шрифты (в репозитории их нет, см. ниже)
assets/hero/             анимация знака из TouchDesigner (сейчас на сайте не показывается)
assets/footer/           ролики подвала из TouchDesigner (сейчас на сайте не показываются)
data/works.js            ВСЁ содержимое: тексты сайта, направления «Подхода», список работ
img/<работа>/NN-t.webp   миниатюра для лент «Подхода» (320 px)
img/<работа>/NN-s.webp   превью для сетки (800 px)
img/<работа>/NN-l.webp   кадр для просмотра (2000 px)
admin/                   админка: работы, кадры, обложки, проекты, «Подход» (/admin/)
tools/prepare_images.py  подготовка новых фотографий (вручную, без админки)
tools/prepare_fonts.py   шрифты → WOFF2
tools/prepare_hero.py    ролик знака из TouchDesigner → assets/hero/
tools/prepare_footer.py  ролики подвала из TouchDesigner → assets/footer/
tools/loops.py           общее для двух скриптов: порог, H.264, постер
tools/agentation-dev.js  панель заметок для Claude (только localhost)
tools/serve.py           локальный сервер; через него же админка сохраняет в папку проекта
```

## Посмотреть локально

```bash
python3 tools/serve.py
```

Затем открыть http://localhost:4173. Сервер слушает всю сеть и при запуске печатает адреса,
поэтому сайт можно открыть с телефона в той же Wi-Fi сети. Вместо `python3 -m http.server` нужен именно он:
Safari на iPhone не проигрывает видео с серверов без поддержки Range-запросов.

## Админка

Всё содержимое сайта — работы, кадры, обложки в архиве, проекты и «Подход» — можно править
на странице **/admin/**: на сайте (`https://…/admin/`) или локально (`http://localhost:4173/admin/`
при запущенном `tools/serve.py`). Ссылки на неё на сайте нет.

- **Фото любого размера** (хоть 250 МБ) перетаскиваются в работу — браузер сам сжимает их
  в три WebP (2000 / 800 / 320 px, как `prepare_images.py`); в репозиторий попадают только они.
  Форматы — всё, что открывает браузер: JPEG, PNG, WebP; HEIC — только в Safari, TIFF — нет.
  Сохранять WebP умеет Chrome (и другие браузеры на Chromium), поэтому админку лучше открывать в нём.
- **Кадры** переставляются мышью, ★ — обложка работы в архиве, «Сетка» — отдельная плитка в архиве.
- **Проекты и «Подход»** — ленты кадров: перетаскивание, «+ Кадры» — выбор из всех работ.
  Первый кадр этапа — его обложка на сайте.
- Удалённый кадр пропадает и из проектов, и из «Подхода»; файл удаляется, только если его
  не использует другая работа (лист лукбука бывает и кадром вещи).

**Где сохраняется.** Локально — прямо в папку проекта (сохранять можно только с этого компьютера),
дальше обычные `git commit` и `git push`. На сайте — одним коммитом в GitHub-репозиторий
от имени того, кто вошёл. Для входа нужен личный GitHub-токен с правом записи в репозиторий
(на странице входа есть ссылка на его создание с нужной галочкой `public_repo`); без него админка
ничего не сохранит — это и ограничивает доступ. Если пока вы правили, в репозиторий пришёл чужой
коммит с изменением `data/works.js`, админка остановится и попросит перезагрузить страницу,
чтобы не затереть чужие правки.

`data/works.js` админка перезаписывает целиком: шапка файла и комментарии над ключами `SITE`
сохраняются, остальные комментарии — нет. Руками файл по-прежнему можно править.

## Добавить работу вручную

1. Сложить фото работы в отдельную папку.
2. Выполнить (нужен Python 3 и Pillow):

   ```bash
   python3 tools/prepare_images.py "путь/к/папке" имя-работы
   ```

3. Скрипт выведет готовый блок — вставить его в начало массива `WORKS`
   в `data/works.js` и заполнить поля. Незаполненные поля на сайте
   показываются как «будет добавлено».

Порядок элементов в `WORKS` задаёт порядок плиток в сетке.
В поле `grid` указываются кадры, которые попадут в сетку:
`size: 's'` — обычная плитка, `'w'` — широкая, `'l'` — большая 2×2.

## Подход

Главная навигация сайта — `SITE.approach` в `data/works.js`. Каждое направление — строка с названием,
фразой для клиента и лентой кадров; клик по названию или кадру открывает «страницу» направления
по ссылке `/#/upcycle` — тот же просмотр, что у работ, но из кадров разных работ, и под каждым кадром
ссылка на исходную работу. Кадры перечисляются в `frames`: `{ work: 'id', i: [номера кадров] }`,
без `i` — все кадры работы. Одна работа может стоять в нескольких направлениях.
Направление без кадров (`frames: []`) показывается с плашкой из поля `soon`.

## Проекты

Блок «Проекты» — `SITE.projects`: каждый проект — путь от эскиза до результата (сейчас К0.1,
сценический костюм, круглая сумка). Этапы идут по порядку, `frames` и `soon` у них такие же,
как у направлений. Проект открывается по ссылке `/#/k01`, «Предыдущая / Следующая» листают этапы.

Порядок страницы: первый экран → архив → проекты → подход → о Полине → контакты.

## Как устроен просмотр

- Любая работа открывается по прямой ссылке: `/#/round-bag/3` (работа и номер кадра).
- На компьютере: стрелки ↑↓ листают кадры, Esc закрывает.
- На телефоне кадры листаются свайпом.
- Панель внизу: «Инверт» (переворачивает сайт целиком: белый лист, чёрный текст, фото позитивом), «Фильтр» (тип и год), 1–4 (плотность сетки), ✕ (сбросить вид).
  Выбор запоминается в браузере. Цветной оригинал фото проявляется при наведении
  (на телефоне — у плитки в центре экрана).
- Единственная стрелка сайта — Forma Icons, line / arrow-right (спрайт `#i-arrow` в `index.html`);
  остальные направления получаются поворотом. «→» в текстах работ превращается в неё же.

## Анимации TouchDesigner

Знак NASEKOLINA с анимацией на первом экране и ролики в подвале с сайта убраны: они отвлекали
от работ. Файлы (`assets/hero/`, `assets/footer/`) и скрипты к ним (`tools/prepare_hero.py`,
`tools/prepare_footer.py`, `tools/loops.py`) пока лежат в репозитории — вернуть блоки можно
из истории git (коммит «Анимации TouchDesigner в знаке и подвале…»).

## Заметки для Claude (Agentation)

На localhost в углу страницы появляется панель [Agentation](https://www.agentation.com/): кликнуть
элемент, написать заметку — Claude получит её вместе с селектором. Работает через MCP-сервер:

```bash
claude mcp add agentation -- npx -y agentation-mcp server
```

После добавления перезапустите сессию Claude Code. Панель грузится с CDN только на localhost
(`tools/agentation-dev.js`, версии закреплены); отключить на странице — `?annotate=0`.
